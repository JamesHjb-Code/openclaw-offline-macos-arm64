# OpenClaw 小龙虾离线安装包（Apple Silicon macOS）

适用于 M1/M2/M3/M4/M5 等 Apple Silicon Mac。

## 下载

请打开本项目右侧的 **Releases**，进入 `v2026.9.5-offline-macos-arm64`，下载：

- `OpenClaw-Offline-macos-arm64.dmg`
- `OpenClaw-Offline-macos-arm64.dmg.SHA256SUMS`

DMG 不会显示在仓库文件列表中，这是因为 GitHub 普通文件有 100 MB 限制，大文件按规范存放在 Release Assets。

## 安装

打开 DMG 后，按顺序双击：

1. `1-安装小龙虾.command`
2. `2-配置API中转站.command`
3. `3-验收小龙虾.command`

详细说明见 DMG 内的 `安装说明书.txt`。

## 版本

- OpenClaw: `2026.9.5 (ec9c1a1)`
- Node.js: `26.10.0`
- macOS architecture: `arm64`
